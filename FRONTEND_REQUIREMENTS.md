This document provides all the necessary technical context for an AI agent to build a frontend for the **VetCare PetMeds** application. The backend is already implemented as a Spring Boot REST API.

## 🚀 Overview
**VetCare PetMeds** is a management system for veterinary clinics, focusing on managing users (Admins, Veterinarians, and Clients), their pets (Animals), and the medications (Medicines) prescribed to those pets.

**Target Environment:** All components run locally.
- **Backend URL:** `http://localhost:8080`
- **Database:** (Managed by backend)

## 🔌 API Endpoints Reference

### 1. Authentication & Users (`/user`)
- `GET /user/all`: List all users.
- `GET /user/{id}`: Get user by ID.
- `GET /user/getEmail?email={email}`: Find user by email.
- `POST /user/create`: Register a new user.
- `POST /user/login`: Authenticate user. 
  - *Payload:* `{ "email": "...", "password": "..." }`
  - *Response:* `ResponseDTO` (contains `user` object and `response` message).
- `PUT /user/update/{id}`: Update user info.
- `DELETE /user/{id}`: Remove user.

### 2. Animals (`/animal`)
- `GET /animal/all`: List all animals.
- `GET /animal/id/{id}`: Get animal by ID.
- `GET /animal/{name}`: Find animals by name.
- `POST /animal/create`: Create a single animal.
- `POST /animal/createAll`: Bulk create animals.
- `POST /animal/addMedicine`: Link a medicine to an animal.
- `PUT /animal/edit/{id}`: Update animal details.
- `DELETE /animal/{id}`: Remove animal.

### 3. Medicines (`/medicine`)
- `GET /medicine/all`: List all medicines.
- `GET /medicine/{id}`: Get medicine by ID.
- `GET /medicine/name/{name}`: Find medicine by name.
- `POST /medicine/create`: Create a single medicine.
- `POST /medicine/createAll`: Bulk create medicines.
- `PUT /medicine/{id}`: Update medicine details.
- `DELETE /medicine/{id}`: Remove medicine.

## 🎨 UI/UX Requirements

### 1. Visual Identity
- **Theme:** Clean, clinical, and professional.
- **Colors:** Medical blue (`#2563eb`), white, and soft greys. Use green for "Success/Healthy" and red for "Alerts/Medicine".
- **Responsive:** Mobile-first design (vets might use tablets/phones).

### 2. Key Pages/Features
- **Login Screen:** Simple email/password form.
- **Dashboard:**
  - **ADM View:** Overview of all users, animals, and medicines.
  - **MED View:** List of patients (animals) and ability to prescribe (add) medicines.
  - **CLIENT View:** View their own pets and active prescriptions.
- **Management Tables:** CRUD interfaces for all entities with search/filter capabilities.
- **Forms:** Validated inputs for data entry (age must be number, email format, etc.).

1. **Setup:** Initialize a Vite + React + TS project.
